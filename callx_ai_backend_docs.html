1 System Architecture & Core Modules Overview

CallX AI is an enterprise-grade AI-powered Cold Calling and CRM Platform built for automated, human-like voice communication across inbound customer reception and outbound sales campaigns.

Key Production Modules:

  • Dashboard & Realtime Analytics: Real-time KPI cards (Total Calls, Daily Volumes, Conversion Success Rates, Pending Follow-ups), task to-do lists, call outcome visual reports, and workspace customization.
  • CRM & Master Leads Directory: Full contact management, qualification scores, geolocation filtering, internal multi-author notes, document attachments (Quotes, Drawings, Proposals), and custom color-coded tags.
  • Voice Agent & Realtime Telephony: Ultra-low latency voice calling powered by Cartesia Sonic TTS and streaming speech recognition, supporting both single direct calls and multi-line batch campaigns (1 to 10 concurrent lines).
  • Email Follow-Up Automation: Post-call dynamic templating with rich HTML variable injection ({name}, {company}, {agent}, {date}), automated sending, and delivery tracking.
  • AI Agent Configuration: Voice persona builder with Cartesia Voice IDs, tone adjustments (Professional, Friendly, Direct, Casual), speech rate controls, outbound cold calling script builder, and 24/7 inbound reception with live human handoffs.

2 Cartesia AI Voice Engine & Realtime Pipeline

The voice pipeline delivers a sub-400ms end-to-end conversational roundtrip (Voice Activity Detection → Speech-to-Text → LLM Token Stream → Cartesia Sonic Voice Synthesis → Telephony Output).

+---------------------------------------------------------------------------------------------------+ | REALTIME CONVERSATIONAL VOICE PIPELINE | +---------------------------------------------------------------------------------------------------+ [ Caller: Phone / Twilio ] | (Bidirectional Audio Stream - µ-law 8kHz / PCM 16kHz) v [ Twilio Media Streams / SIP WebSocket Gateway ] | +---> [ VAD & Deepgram Nova-2 Streaming STT ] (Realtime Transcription) | | | v | [ LLM Orchestrator (GPT-4o / Claude 3.5) ] (Inbound/Outbound Scenario Prompt) | | (Streams Tokens as they are generated) | v | [ Cartesia Sonic WebSocket API (wss://api.cartesia.ai/tts/websocket) ] | | (Ultra-low latency audio chunks generation < 90ms) | v [ Audio Player & Streamer ] ---> [ Caller hears natural voice ] | (Interruption / Barge-in Detection: Immediately cuts Cartesia playback if user speaks) +---------------------------------------------------------------------------------------------------+

4 RESTful & WebSocket API Specification

4.1. Authentication & Session

POST /api/v1/auth/login
Authenticate administrator or agent and return JWT bearer token.
Request: { "email": "admin@callx.ai", "password": "your_secure_password" }
Response (200): { "token": "eyJhbGciOi...", "user": { "id": 1, "name": "Admin User", "role": "admin" } }

4.2. Leads & Customer Management (CRM)

GET /api/v1/customers
Retrieve filtered, sorted, paginated leads directory.
Query: ?search=john&leadStatus=Qualified&leadPriority=Hot&city=Vancouver&page=1&limit=25
POST /api/v1/customers
Create a new customer lead record with qualification scores and tags.
GET /api/v1/customers/:id
Fetch full customer profile including notes, documents, and call history.
POST /api/v1/customers/:id/notes
Append a new internal or AI note to customer timeline.
POST /api/v1/customers/:id/documents
Upload attachment file (Multipart form-data: file, type, name).

4.3. Voice Calls & Batch AI Campaigns (Cartesia Engine)

POST /api/v1/calls/dispatch-single
Initiate an immediate or scheduled outbound AI cold call to a specific contact.
Request: { "customerId": 42, "scenarioId": "sc_01", "cartesiaVoiceId": "sonic-english-emma" }
Response (202): { "status": "Queued", "callSessionId": "cs_99412", "phone": "+16045550199" }
POST /api/v1/calls/launch-batch-campaign
Launch high-volume cold calling campaign across 1 to 10 concurrent lines.
Request: { "customerIds": [10, 11, 12, 13], "scenarioId": "sc_01", "concurrentLines": 5 }
WS /ws/media-stream/:callSessionId
Bidirectional Telephony & Cartesia Audio Stream Gateway (Twilio Media Stream ↔ Backend ↔ Cartesia Sonic).

4.4. Inbound Call Handling Webhook

POST /api/v1/telephony/inbound-webhook
Twilio Inbound Voice Webhook: Returns TwiML WebSocket Stream configuration.
Response (TwiML): <Response><Connect><Stream url="wss://api.callx.ai/ws/media-stream/in_123"/></Connect></Response>

4.5. Automated Email Follow-ups

POST /api/v1/emails/send
Dispatch single or bulk follow-up email rendered with customer variables.

5 Production Architecture & Recommended Tech Stack

Production Stack Specifications:
  • Backend Framework: Node.js (NestJS / TypeScript) or Python (FastAPI / AsyncIO).
  • Database & ORM: PostgreSQL 16+ with Prisma ORM / SQLAlchemy.
  • Job & Call Queue Management: Redis + BullMQ (Handles concurrent outbound dialing 1-10 lines and retry queues).
  • Voice Synthesis (TTS): Cartesia Sonic WebSocket API (Low-latency streaming < 90ms).
  • Speech-to-Text (STT): Deepgram Nova-2 Streaming WebSocket (Ultra-fast speech transcription & VAD).
  • LLM Intelligence: OpenAI GPT-4o / Anthropic Claude 3.5 Sonnet (Function calling for CRM updates and email actions).
  • Object Storage: AWS S3 / Cloudflare R2 (Audio recordings & customer PDF documents).

5.1. Cartesia WebSocket Streaming Implementation (Node.js Example)

import Cartesia from "@cartesia/cartesia-js"; const cartesia = new Cartesia({ apiKey: process.env.CARTESIA_API_KEY }); const ws = cartesia.tts.websocket({ container: "raw", encoding: "pcm_mulaw", sampleRate: 8000 }); // Stream LLM tokens to Cartesia and send audio directly to Twilio Media Stream async function streamResponseToTwilio(llmTokenStream, twilioStreamWs, streamSid) { const response = await ws.send({ model_id: "sonic-english", voice: { mode: "id", id: "a0e99841-438c-4a64-b679-ae501e7d6091" }, // Emma Voice ID transcript: llmTokenStream, language: "en" }); for await (const chunk of response.events("media")) { // Send 8kHz mulaw audio packet to caller with zero buffer delay twilioStreamWs.send(JSON.stringify({ event: "media", streamSid: streamSid, media: { payload: Buffer.from(chunk.data).toString("base64") } })); } }
