۱ معرفی و چشم‌انداز کلی سیستم (Overview)

سامانه CallX AI یک پلتفرم جامع جهت برقراری ارتباطات هوشمند، مدیریت فرآیند فروش و تماس‌های خودکار است. سیستم از بخش‌های زیر تشکیل شده است:

  • CRM & Lead Management: مدیریت متمرکز اطلاعات مخاطبان، سازمان‌ها، وضعیت‌های فروش، نوت‌ها و مدارک پیوست.
  • Voice Call Center: ثبت تماس‌های ورودی و خروجی، زمان‌بندی تماس‌های خودکار ایجنت هوش مصنوعی، فایل صوتی و پیاده‌سازی متنی (Transcript).
  • Email Follow-Ups: ارسال خودکار و زمان‌بندی‌شده ایمیل‌های پس از مکالمه با قالب‌های پویا.
  • AI Scenarios & Prompt Engine: پیکربندی سناریوهای صوتی، پرسش‌های ارزیابی کیفی (Qualifying Questions) و تنظیمات لحن/صدا.

۲ مدل داده‌ای و ساختار جداول دیتابیس (Database ERD)

طراحی جداول بر پایه استاندارد ارتباطی (Relational / PostgreSQL) به شرح زیر است:

۳ مستندات کامل APIها (RESTful Endpoints)

۳.۱. احراز هویت (Auth)

POST /api/v1/auth/login
ورود به سیستم و دریافت JWT Token
Request: { "email": "admin@callx.ai", "password": "secure_password" }
Response (200): { "token": "jwt_token_here", "user": { "id": 1, "name": "Admin", "role": "admin" } }

۳.۲. مدیریت مشتریان (Customers)

GET /api/v1/customers
دریافت لیست مشتریان با فیلتر وضعیت، اولویت، جستجو و صفحه‌بندی (Pagination)
Query Params: ?search=john&leadStatus=Qualified&leadPriority=Hot&page=1&limit=20
POST /api/v1/customers
ثبت مشتری یا لید جدید
GET /api/v1/customers/:id
دریافت جزئیات پرونده یک مشتری به همراه نوت‌ها و لیست اسناد پیوست
POST /api/v1/customers/:id/notes
ثبت یادداشت جدید برای مشتری
Request: { "content": "مشتری خواستار تخفیف برای پلن سازمانی شد.", "author": "Sara Agent" }
POST /api/v1/customers/:id/documents
آپلود سند یا پیش‌فاکتور (ارسال به‌صورت multipart/form-data)

۳.۳. مدیریت تماس‌ها و هوش مصنوعی صوتی (Calls & Voice Engine)

GET /api/v1/calls
دریافت گزارش تماس‌ها با قابلیت فیلتر تاریخ و وضعیت
POST /api/v1/calls/trigger-ai-call
درخواست ایجاد تماس خودکار توسط بات صوتی با سناریوی مشخص
Request: { "phone": "+1234567890", "customerId": 105, "scenarioId": "1" }
Response (202): { "status": "Queued", "callId": "c_99812", "message": "تماس در صف ارسال قرار گرفت." }

۳.۴. ایمیل‌های پیگیری و قالب‌ها (Emails)

GET /api/v1/email-templates
دریافت لیست تمام قالب‌های آماده ایمیل
POST /api/v1/emails/send
ارسال ایمیل پیگیری به مشتری با جایگذاری خودکار متغیرها

۳.۵. داشبورد و شاخص‌های کلیدی (Dashboard KPIs)

GET /api/v1/dashboard/stats
دریافت آمار کلی (تعداد لیدها، تماس‌های موفق، نرخ تبدیل و پیگیری‌های امروز)

۴ معماری فنی پیشنهادی بک‌اند (Recommended Stack)

💡 ساختار پیشنهادی:
  • فریم‌ورک بک‌اند: Node.js (NestJS / Express + TypeScript) یا Python (FastAPI).
  • پایگاه داده: PostgreSQL به همراه Prisma ORM یا TypeORM / SQLAlchemy.
  • مدیریت صف و کش: Redis + BullMQ (برای صف‌بندی تماس‌ها و ایمیل‌های زمان‌بندی‌شده).
  • ارتباط تماس صوتی: Twilio Voice API / LiveKit به همراه OpenAI Realtime API / Deepgram STT.
