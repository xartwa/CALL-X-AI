1 Executive Summary & Cartesia Voice Agent Model

CallX AI is an enterprise AI Voice Cold Calling & CRM Platform powered exclusively by Cartesia Voice Agent (https://cartesia.ai/) for all conversational intelligence, speech recognition, real-time turn-taking, and hyper-realistic sonic voice generation.

Why Cartesia Voice Agent?

  • All-in-One Voice Agent Architecture: Eliminates fragmented multi-vendor latency by consolidating VAD (Voice Activity Detection), STT, Conversational Context, Tool Execution, and Sonic TTS into a unified Cartesia Voice Agent session.
  • Ultra-Low Latency (~90ms TTS / <350ms Total Roundtrip): Industry-leading response speeds creating genuine, human-like voice conversations without awkward pauses.
  • Natural Turn-Taking & Interruption (Barge-in): Cartesia Voice Agent natively detects when the customer speaks mid-sentence, stops speaking immediately, and listens attentively.
  • Dynamic Tool Calling (Function Execution): Cartesia Voice Agent directly invokes backend webhooks to update lead scores, log qualification answers, trigger follow-up emails, or initiate live warm transfers.

2.1. Inbound vs. Outbound Cold Calling Workflows

Lifecycle Stage Outbound Cold Calling Campaign Inbound Reception & Support Agent
Trigger Mechanism Manual click, scheduled follow-up date, or Batch Campaign (1-10 concurrent lines). Customer dials dedicated company Twilio/SIP phone number.
Greeting & Opening Agent speaks first with scenario-defined openingGreeting and value pitch. Agent answers immediately with company reception greeting & business hours verification.
Qualification & Triage Asks defined qualifyingQuestions to score lead (Hot, Warm, Cold, Lost). Identifies caller's intent, answers inquiries from FAQ knowledge base, and logs details.
Handoff & Next Steps Cartesia Agent invokes backend webhook to dispatch dynamic HTML follow-up email & tag CRM. Resolves query, books a callback appointment, or executes a live warm transfer to a human agent.

4 RESTful & WebSocket API Specification

4.1. Cartesia Voice Agent Dispatch & Campaigns

POST /api/v1/calls/dispatch-single
Initiate an immediate or scheduled outbound cold call via Cartesia Voice Agent.
Request Body:
{
  "customerId": 108,
  "scenarioId": "sc_b2b_outreach",
  "cartesiaVoiceId": "sarah",
  "scheduledAt": null
}
Response (202 Accepted):
{ "status": "Queued", "callSessionId": "cs_cartesia_8819", "targetPhone": "+16045550199" }
POST /api/v1/calls/launch-batch-campaign
Launch high-volume cold calling campaign across 1 to 10 concurrent lines.
Request Body:
{
  "customerIds": [101, 102, 103, 104, 105],
  "scenarioId": "sc_b2b_outreach",
  "concurrentLines": 5
}
WS /ws/cartesia-bridge/:callSessionId
Full-duplex WebSocket Audio Stream between Telephony Media Streams & Cartesia Voice Agent API.
POST /api/v1/cartesia/tool-callback
Webhook endpoint invoked by Cartesia Voice Agent when executing CRM tools (e.g. Update Lead Status, Schedule Callback, Send Follow-up Email).
Request from Cartesia:
{
  "tool": "update_lead_qualification",
  "customerId": 108,
  "qualification": { "status": "Qualified", "priority": "Hot", "notes": "Interested in 5 enterprise lines" }
}

5 Production Architecture & Cartesia Agent SDK Implementation

Production Architecture Stack:
  • Backend Core: Node.js (NestJS / TypeScript) or Python (FastAPI / AsyncIO).
  • Voice Agent SDK: @cartesia/cartesia-js (Cartesia Voice Agent WebSocket API).
  • Telephony Gateway: Twilio Voice Media Streams (Bidirectional 8kHz µ-law WebSocket) or LiveKit.
  • Database: PostgreSQL 16+ with Prisma ORM / SQLAlchemy.
  • Concurrency & Queue Management: Redis + BullMQ (Handles 1-10 concurrent lines dialing and retry queues).
  • Storage: AWS S3 / Cloudflare R2 (for call recordings and PDF documents).

5.1. Cartesia Voice Agent WebSocket Bridge (Node.js Reference Implementation)

import WebSocket from 'ws'; import Cartesia from '@cartesia/cartesia-js'; const cartesia = new Cartesia({ apiKey: process.env.CARTESIA_API_KEY }); // Handle Twilio Telephony Media Stream Connection export function setupCartesiaVoiceBridge(twilioWs, callSession) { // Initialize Cartesia Voice Agent Session const cartesiaAgentWs = cartesia.agents.connect({ agentId: callSession.cartesiaAgentId, sampleRate: 8000, encoding: "pcm_mulaw" }); let streamSid = null; // 1. Forward Audio from Caller (Twilio) to Cartesia Voice Agent twilioWs.on('message', (message) => { const data = JSON.parse(message); if (data.event === 'start') { streamSid = data.start.streamSid; } else if (data.event === 'media') { const audioBuffer = Buffer.from(data.media.payload, 'base64'); cartesiaAgentWs.sendAudio(audioBuffer); } }); // 2. Stream Synthesized Voice Audio from Cartesia back to Caller cartesiaAgentWs.on('audio', (audioChunk) => { if (streamSid) { twilioWs.send(JSON.stringify({ event: 'media', streamSid: streamSid, media: { payload: Buffer.from(audioChunk).toString('base64') } })); } }); // 3. Handle Cartesia Voice Agent Tool Calls (CRM Auto-Update) cartesiaAgentWs.on('tool_call', async (toolCall) => { if (toolCall.name === 'update_customer_lead') { await updateCustomerCRM(callSession.customerId, toolCall.arguments); } }); }
